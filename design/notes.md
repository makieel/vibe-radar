- 정적 페이지 하나(`web/index.html` + `history.js`), 서버 없음
- GitHub Actions가 매일 09:00 KST에 HN · GitHub Trending · arXiv 수집 → `data/YYYY-MM-DD.json` 커밋 → 최근 90일을 `history.js`로 빌드 → GitHub Pages 배포

## 디자인 시안 v1 — `mockup-v1-3directions.html`
- A · 관제실: 검은 바탕 네온 터미널, 흐르는 뉴스 띠, 깜빡이는 보안 경보
- B · 신문 1면: 종이색 바탕 명조 "개발자 조간", 핫이슈 1면 기사 + 해설, 3단 칼럼
- C · 벤토 그리드: 보라·청록 그라데이션 위 크기가 다른 유리 카드

## 디자인 시안 v2 — `mockup-v2-AplusC.html`
사용자 요청: A와 C의 장점을 살린 다른 시안 3가지
- D · 네온 벤토: A의 검은 격자 바탕·네온·뉴스 띠 + C의 벤토 카드. 핫이슈마다 열기 막대, 통계 카드에 스파크라인, ⌘K 검색창
